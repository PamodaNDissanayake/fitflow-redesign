## Project Overview

FitFlow is a fitness application redesign focused on personalized
workouts, private community interaction, easier nutrition logging
and clear progress tracking.

This repository contains the proposed technology stack,
comparison matrices, architecture and initial project structure.

## Main Features

- AI-powered personalized workout plans
- Private social circles and community challenges
- Camera-assisted nutrition logging with manual correction
- Progress tracking and milestone feedback
- Offline workout access and synchronization

## Proposed Technology Stack

| Component | Technology |
|---|---|
| Mobile frontend | React Native and TypeScript |
| Web frontend | React Native Web |
| Backend API | Node.js and Express |
| Database | Cloud Firestore |
| Authentication | Firebase Authentication |
| AI service | Python and FastAPI |
| Mobile machine learning | LiteRT and ML Kit |
| Cache | Redis when required |
| Images | Private object storage |
