# FitFlow Frontend

## Purpose

Provide the FitFlow interface for Android, iOS and web users.

## Proposed Technologies

- React Native
- TypeScript
- React Native Web

## Main Screens

1. Home Dashboard
2. AI Workout Planner
3. Progress Tracking
4. Community Feed
5. Nutrition Logger

## Main Responsibilities

- Display personalized workout plans and their explanations.
- Allow users to accept or adjust workout suggestions.
- Show progress charts and milestones.
- Provide access to private circles and challenges.
- Support camera-assisted and manual meal logging.
- Cache approved workouts for offline access.
- Queue offline workout records for synchronization.

## Usability Improvements

Based on Lab Exercise 04:

- Use the label "Today's Workout".
- Display a visible "Why this workout?" link.
- Add a "Log Meal" label beside the camera action.
- Use clear navigation labels.
- Improve chart text readability.
- Display "Private - invite only" on private circles.

## Platform Considerations

Camera access, secure storage, offline persistence and mobile
machine learning require platform-specific adapters.

Browser users must have a manual nutrition logging fallback.
